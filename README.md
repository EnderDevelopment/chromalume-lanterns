# Minecraft Bedrock Adjustable Lantern Add-on

Chromalume Lanterns is a Minecraft Bedrock add-on that adds a craftable, placeable lantern with adjustable RGB particle color and visual aura brightness. Its lantern controls let you tune red, green, and blue values independently and set aura brightness from 0 to 15; the block’s actual light emission remains fixed at level 15.

## Install

1. Import the behavior pack and resource pack together as an `.mcaddon`, or import each pack separately.
2. Enable both packs on your world. Enable Script API or Beta APIs if your Minecraft version requests them.
3. Use a crafting table to make the lantern with one torch in the center and eight iron nuggets around it.

## Use

1. Place the lantern on the top or underside of a supporting block. Side-face placement is not supported.
2. Interact with the placed lantern to open its controls.
3. Adjust the Red, Green, and Blue sliders to choose a color, then set the visual aura brightness from 0 to 15.
4. Close the form to save the settings for that lantern. Brightness 0 turns off its particle aura.
